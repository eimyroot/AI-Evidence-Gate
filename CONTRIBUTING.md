# Contributing

Thanks for contributing to AI-Evidence-Gate.

- Open an issue for substantial evaluation, release-gate, schema, architecture, or deployment changes.
- Keep changes narrowly scoped and avoid unrelated refactors.
- Never commit credentials, secrets, production data, model-provider secrets, or sensitive evaluation samples.
- Preserve evidence-first and fail-closed behavior for release decisions.

Use the development and validation commands documented in the repository. Run the relevant backend, frontend, build, evaluation, and browser checks before opening a pull request.

Pull requests should explain what changed, why, how it was tested, and any evaluation, release, compatibility, security, or rollback impact.

By contributing, you agree that your contribution is submitted under the repository's existing license and project terms unless a separate written agreement applies.
